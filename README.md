# Mes jeux mobiles

Collection de petits jeux HTML (un fichier par jeu), jouables sur téléphone ou ordinateur.

Ouvrir `index.html` pour le menu de tous les jeux.

- **Éducatifs** : Néon Mots, Néon Tables, Néon Tri, Fraction Slice, Rhythm Spell, Mot à Mot
- **Arcade** : Hook Rush, Neon Putt, Maze Slide, Beat Dash, Horde Rush, Parcours du Petit Singe, Matou Dash, Duel au Crépuscule, Rocket Tap, Vanishing Steps, Pulse Tunnel, Endless Drop, Gravity Flip, Tiny Ninja, Cube Dash
